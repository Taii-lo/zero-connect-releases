# Zero Connect – signed update files

This repository only hosts the **signed update files** that Zero Connect devices read
(`channels.json`, `beta-access.json`, `releases/<version>/…`). It contains no source code
and no vehicle photos. Every file is signed; devices reject anything that does not verify.

Zero Connect is an independent, unofficial project and is not affiliated with Zero Motorcycles.
Nothing here is meant to be installed by hand.
